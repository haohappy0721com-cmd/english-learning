# English Mastery

An interactive English learning website with vocabulary flashcards, grammar exercises, reading comprehension, and quizzes.

## Features

- **Vocabulary Builder** — Flip-through flashcards with words, phonetics, definitions, and example sentences across Beginner/Intermediate/Advanced levels
- **Grammar Practice** — Multiple-choice quizzes on tenses, prepositions, and articles with instant feedback
- **Reading Comprehension** — Read passages and answer questions at Easy/Medium/Hard difficulty
- **Quick Quiz** — Mixed-topic quizzes combining vocabulary, grammar, and reading questions
- **Progress Tracking** — Words learned, day streak, quizzes completed, and accuracy stats (stored locally)
- **Dark/Light Theme** — Toggle between light and dark mode

## Usage

Open `index.html` in any browser to start learning.
